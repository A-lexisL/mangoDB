# Changelog For mangoDB
All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [milestone3] - 2026-11-13
### Added
- Thread pool manager
- Worker lifecycle
- Task architecture

## [milestone2] - 2026-11-4
### Added
- **!(breaking change)** Multithread implementation
- Thread pool and query runner
- Database and table synchronization
- Main thread Management(InputReader, OutputBuffer, QueryDispatcher and QueryManager)

## [milestone3] - 2026-10-21
### Added
- Import source code
- Cmake
- Code quality check
- COPYTABLE, TRUNCATE, DELETE and DUPLICATE
- SWAP and SUB
- SELECT
- SUM and MAX
- custom test cases and local test script for one custom test case at a time.
